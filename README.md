# Yacht regression lab

첨부 엑셀 `ship_regression (2).xlsx`의 원본자료 F5:G312(308행)를 바탕으로 만든 JavaScript 회귀 실습 웹앱입니다. HTML/CSS/JavaScript만 사용하며 설치와 빌드가 필요 없습니다.

## 실행
모든 파일을 같은 폴더에 둔 뒤 `index.html`을 브라우저로 열면 됩니다. 코드 실습의 Web Worker는 일부 브라우저에서 로컬 파일 실행 시 제한될 수 있습니다. 그 경우 배포 사이트나 로컬 웹서버에서 실행하세요.

## GitHub 업로드
1. ZIP 압축을 풉니다.
2. 저장소의 Add file → Upload files에서 내부 파일들을 업로드합니다.
3. 공개 웹페이지가 필요하면 Settings → Pages에서 업로드한 브랜치의 루트 폴더를 배포 대상으로 선택합니다. 파일은 선택한 브랜치의 루트에 있어야 합니다.

기존 파일과 이름이 같으면 내용을 확인하고 교체하세요. 제공 파일에는 Sites 내부 설정이나 인증정보가 들어 있지 않습니다.

## 계산
`regression.js`의 `fitRegression(points)`는 `[X,Y]` 배열을 받아 선형·2차 회귀 계수, R², RMSE, 예측 함수를 반환합니다. 엑셀의 중심합 기반 최소제곱식과 같습니다. 2차 회귀는 계수에 대해서는 선형인 다항회귀이며 엄밀한 비선형 계수 추정은 아닙니다.

- 선형: Y = 121.667572X − 24.484070, R²=0.656249, RMSE=8.874191
- 2차: Y = 871.030969X² − 379.175235X + 38.665675, R²=0.925326, RMSE=4.136098

308개 원본자료 결과를 독립적인 최소제곱 계산과 비교했습니다. 상수 X와 서로 다른 X가 2개뿐인 입력의 오류 처리도 확인했습니다.

## 데이터와 한계
원본 CSV는 엑셀의 7개 변수를 보존합니다. 분석은 프루드 수와 잔여저항/배수중량 비만 사용합니다. 프루드 수는 실제 속도(knots)가 아닙니다. 22개 선체를 합친 단변량 모형으로 형상 차이와 미관측 선체의 성능을 검증하지 않았습니다. 음수 예측과 외삽에는 주의해야 합니다.

엑셀에 기재된 출처: Gerritsma, Onnink & Versluis (1981), UCI Yacht Hydrodynamics, DOI 10.24432/C5XG7R, CC BY 4.0.
https://archive.ics.uci.edu/dataset/243/yacht+hydrodynamics

코드 실습은 별도 Worker에서 predict 함수를 실행하고 2초 초과 시 중단합니다. 실습 함수는 세 입력값의 예측 결과만 바꾸며 회귀 모형의 계수를 다시 적합하지 않습니다.
